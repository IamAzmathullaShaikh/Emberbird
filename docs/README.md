# WSABuilds Documentation Tree

This directory contains tiered documentation for the WSABuilds platform.

## Hierarchy
- `getting-started/`: Quick start, beginner, and manual installation walkthroughs.
- `configuration/`: Magisk, Zygisk, Play Integrity, and ADB networking setups.
- `troubleshooting/`: Diagnostic decision trees and error code resolutions.
- `community/`: Discussions governance, code of conduct, and moderation guidelines.
